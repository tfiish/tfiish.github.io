# Agent notes

## Prose rules

These apply to all copy on the page and to any docs in this repo.

1. Use the Oxford comma in any list of three or more nouns or noun phrases: "games, tools, and experiments", not "games, tools and experiments".
2. Set em dashes closed, directly between words: "this—like this—works", never with a space on either side: "this — like this — doesn't".
