# Agent notes

## Prose rules

These apply everywhere: copy on the page, code comments, and docs.

1. Use the Oxford comma in any list of three or more nouns or noun phrases: "games, tools, and experiments", not "games, tools and experiments". It holds before an ampersand too: "maps, charts, & globes".
2. Set em dashes closed, directly between words: "this—like this—works", never with a space on either side: "this — like this — doesn't". In Markdown, a dash at the start or end of a line counts as spaced, since the line break renders as a space. When a dash wants padding, it shouldn't be a dash: use a full stop or the separator.
3. The separator is a spaced middle dot, ` · `, and it has one job: joining two sibling facts, or a phrase to its attribution ("side projects · last updated 2026-10-21"). Don't use `•` or a spaced dash for it.
4. Dates are ISO, `2026-10-05`, in docs and on the page.

## Voice

Quiet and plain. No hype, no urgency, and no stacked exclamation marks: one at most, kept for a moment that earns it.
