1QRL

1qrl.app 1qrl.cc Porkbun Onespot repo

Tiny links, big QRs. A URL shortener whose short links encode into low-density QR codes that still scan from across a room.

Next.js · React · TypeScript · Tailwind · Supabase (Postgres, auth) · Vercel, with a Vercel cron and pg_cron · ships via npm run deploy

Managing

  • A Onespot product. Mail, legal, and routing all go through that entity; the contact address is hi@1qrl.app.
  • Both domains at Porkbun on auto-renew. A lapse kills every short link at once, so confirm auto-renew and the card yearly.
  • Two Supabase projects, staging and production. A daily cron pings both so the free tier doesn't pause them.
  • Auth email goes out through Resend. A weekly DMARC summary lands in hi@.
  • Monthly: Supabase and Vercel usage, Resend quota, Search Console. Every five months: sign in with Google on staging and production so Google doesn't delete the OAuth clients.

Whole Wide World

wholewideworld.app Porkbun repo

A mobile-first web app that uses spaced repetition to teach where every country, state, and province is, on a globe you can spin and zoom.

Vite · React · TypeScript · PWA with a service worker · all data in IndexedDB, no server · d3-geo · ts-fsrs · Cloudflare Pages, built from the release branch

Managing

  • Own domain at Porkbun, auto-renew on. Check it a few weeks before the yearly renewal.
  • Cloudflare does everything else: Pages builds on every push to release, issues the certificate, redirects www, and runs Email Routing.
  • Mail to hi@wholewideworld.app forwards to the Gmail inbox. Catch-all is off, so any other address is dropped. Send a test mail now and then.
  • No server and no accounts. Reader progress lives in their own browser.
  • Yearly: Natural Earth data and the UN member list, plus a re-read of the Terms and Privacy policy. Push main to the private GitHub repo by hand after each commit; nothing pushes on its own.

Unspoiled

unspoiled.xyz Porkbun repo

Spoiler-free sports highlights aggregator.

pnpm monorepo · Next.js 15 web app on Vercel · Supabase Postgres · ingest worker on GitHub Actions

Managing

  • Domain at Porkbun. Hosted on Vercel under the personal account, reading from Supabase.
  • Ingest runs on GitHub Actions: a full daily pass, and an hourly video pass fired by an outside cron service because GitHub's own schedule is unreliable at that cadence.
  • A weekly audit posts findings to a GitHub issue every Monday. A quarterly drift audit, run by Claude Code, posts to a long-lived issue. Read both: a skipped or stuck run looks exactly like a clean one.
  • UptimeRobot watches the site. Quarterly, send a test alert to confirm the monitors and contact still exist.
  • hi@unspoiled.xyz and the suggestions form both deliver through Resend. Monthly, send a test from an outside address and submit the form.
  • PostHog handles analytics, cookieless. Quarterly, confirm the privacy settings the policy promises are still set.
  • A couple of tokens expire yearly. Rotate them together, ahead of time; an expired one degrades quietly rather than failing loudly.

Mark Madness

markmadness.vercel.app no custom domain repo

The official portal for all things Mark Madness.

Vite · React · TypeScript · Tailwind · shadcn/Radix · Vercel Hobby plan

Managing

  • Backend is Lovable Cloud, which is Supabase underneath: auth, database, and edge functions. Migrations are managed centrally and never run locally.
  • Vercel Hobby only deploys pushes from the repo owner. After merging someone else's PR, push an empty commit to main to trigger the deploy. Cap is 100 deploys a day, so batch pushes.
  • Backend credentials live in a gitignored .env, never in the repo.

StoryStamper

GitHub, public Mac app repo

A native, lightweight Mac app to quickly add Instagram-story-style text blocks to a vertical video.

Swift 6 · SwiftUI · Swift Package, no Xcode project · FFmpeg for export · ad-hoc signed, not notarized · built with Scripts/make-app.sh

Managing

  • Nothing to manage: no hosting, no accounts, no domain, nothing runs on a schedule. It ships as source.
  • Building needs macOS 14 or later and Xcode 16 or the Command Line Tools. Export needs FFmpeg from Homebrew.
  • A build copied to another Mac needs right-click, Open the first time since it isn't notarized.
