Unspoiled

unspoiled.xyz Porkbun repo

Spoiler-free sports highlights aggregator.

pnpm monorepo · Next.js 15 web app on Vercel · Supabase Postgres · ingest worker on GitHub Actions

Managing

  • Domain at Porkbun. Hosted on Vercel under the personal account, reading from Supabase.
  • Ingest runs on GitHub Actions: a full daily pass, and an hourly video pass fired by an outside cron service because GitHub's own schedule is unreliable at that cadence.
  • A weekly audit posts findings to a GitHub issue every Monday. A quarterly drift audit, run by Claude Code, posts to a long-lived issue. Read both: a skipped or stuck run looks exactly like a clean one.
  • UptimeRobot runs two monitors and emails when either goes down: one polls the site every 5 minutes, so Down means readers can't reach it; the other polls the health endpoint every 45 minutes, so Down means the site is fine but the ingest cron has stopped and the archive isn't growing.
  • Emailing hi@ delivers through Resend, as does the suggestions form.
  • PostHog handles analytics, cookieless.
  • A couple of tokens expire yearly (CLAUDE_CODE_OAUTH_TOKEN for the drift audit, GITHUB_DISPATCH_TOKEN for the hourly trigger). Rotate them together, ahead of time; an expired one degrades quietly rather than failing loudly.

Whole Wide World

wholewideworld.app Porkbun repo

A mobile-first web app that uses spaced repetition to teach where every country, state, and province is, on a globe you can spin and zoom.

Vite · React · TypeScript · PWA with a service worker · all data in IndexedDB, no server · d3-geo · ts-fsrs · Cloudflare Pages, built from the release branch

Managing

  • Own domain at Porkbun, auto-renew on.
  • Cloudflare does everything else: Pages builds on every push to release, issues the certificate, redirects www, and runs Email Routing.
  • Mail to hi@ forwards to the Gmail inbox. Catch-all is off, so any other address is dropped.
  • No server and no accounts. Reader progress lives in their own browser.
  • Yearly: Natural Earth data and the UN member list.
