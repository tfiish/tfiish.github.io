Unspoiled

unspoiled.xyz Porkbun </>

Spoiler-free sports highlights aggregator.

pnpm monorepo · Next.js 15 web app on Vercel · Supabase Postgres · ingest worker on GitHub Actions

Managing
  • Domain at Porkbun. Hosted on Vercel under its own account, reading from Supabase.
  • Highlights come from the YouTube Data API and play through YouTube embeds; a lapsed or over-quota API key means no new videos. Reddit game-thread links come from Arctic Shift, a one-person Reddit archive with no uptime guarantee.
  • Ingest runs on GitHub Actions: a full daily pass, and an hourly video pass fired by an outside cron service because GitHub's own schedule is unreliable at that cadence.
  • A weekly audit posts findings to a GitHub issue every Monday. A quarterly drift audit, run by Claude Code, posts to a long-lived issue.
  • UptimeRobot runs two monitors and emails when either goes down: one polls the site, so Down means readers can't reach it; the other polls the health endpoint, so Down means the site is fine but ingest has stopped.
  • The hi@ inbox is Zoho Mail, which also receives the suggestions form. Outbound mail, including the form, delivers through Resend.
  • PostHog (EU cloud) handles analytics (cookieless) and error tracking.
  • Two tokens expire yearly: an Anthropic token for the drift audit and a GitHub personal access token for the hourly trigger. Rotate them together, ahead of time.

Whole Wide World

wholewideworld.app Porkbun </>

A mobile-first web app that uses spaced repetition to teach where every country, state, and province is, on a globe you can spin and zoom.

Vite · React · TypeScript · PWA with a service worker · progress in IndexedDB on the reader's device · d3-geo · ts-fsrs · Cloudflare Pages, built from the release branch · a Cloudflare Worker with Durable Objects for Magic Transfer, deployed by hand with Wrangler

Managing
  • Own domain at Porkbun, auto-renew on. DNS lives at Cloudflare, not Porkbun.
  • Cloudflare does everything else: Pages builds on every push to release on GitHub, so the repo is part of the deploy path; it also issues the certificate, redirects www, runs Email Routing, and hosts the Magic Transfer relay.
  • The Magic Transfer relay is a Cloudflare Worker on /api/transfer/*, on the Workers Free plan. It doesn't deploy from GitHub: run pnpm relay:deploy (Wrangler, logged in on the Mac) whenever relay/ changes, before shipping.
  • Mail to hi@ forwards to the Gmail inbox via Cloudflare Email Routing. Catch-all is off, so any other address is dropped.
  • PostHog (EU cloud) handles analytics (cookieless) and error tracking.
  • No accounts. Reader progress lives in their own browser; Magic Transfer passes an encrypted copy through the relay, which deletes it once it's taken or after 15 minutes.
  • Yearly: refresh the Natural Earth data and the UN member list, and check the relay with the curl in the README.

  • Sign in with Google on staging every five months or so, so Google doesn't retire the unused OAuth client.
