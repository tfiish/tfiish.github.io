Tyler Fisher

Side projects, in no particular order.

  • 1QRL

    Tiny links, big QRs. A URL shortener whose short links encode into low-density QR codes that still scan from across a room.

    Next.js · React · TypeScript · Tailwind · Supabase (Postgres, auth) · Vercel, with a Vercel cron and pg_cron · ships via npm run deploy

  • Whole Wide World

    A mobile-first web app that uses spaced repetition to teach where every country, state, and province is, on a globe you can spin and zoom.

    Vite · React · TypeScript · PWA with a service worker · all data in IndexedDB, no server · d3-geo · ts-fsrs · Cloudflare Pages, built from the release branch · domain at Porkbun

  • Unspoiled

    Spoiler-free sports highlights aggregator.

    pnpm monorepo · Next.js 15 web app on Vercel · Supabase Postgres · ingest worker runs on GitHub Actions cron, hourly and daily

  • Mark Madness

    The official portal for all things Mark Madness.

    Vite · React · TypeScript · Tailwind · shadcn/Radix · Supabase (auth, database, edge functions) · Vercel Hobby plan, so only the repo owner's pushes deploy · started in Lovable

  • StoryStamper

    A native, lightweight Mac app to quickly add Instagram-story-style text blocks to a vertical video.

    Swift 6 · SwiftUI · Swift Package, no Xcode project · FFmpeg for export · ad-hoc signed, not notarized · distributed as source on GitHub, built with Scripts/make-app.sh
